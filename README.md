# DivideMe
*本项目仅供个人学习使用，禁止未经授权的二次分发、商业使用或修改后分发。*

## 项目简介

DivideMe 是一个基于 Scala 3 的厨房模拟器项目

## 环境要求

- **Scala**: 3.8.3
- **构建工具**: sbt
- **JDK**: 需要 JDK 21

### 运行项目

```bash
sbt run
```

### 编译项目

```bash
sbt compile
```
